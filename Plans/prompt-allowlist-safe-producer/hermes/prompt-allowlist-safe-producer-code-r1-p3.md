# Hermes code review r1 — part 3/3 (plugin), 2026-09-28

FINDINGS:
F1 [HIGH] sink.py: Sink._send / Sink._post — Revocation is checked once before grouping, not before each HTTP call; this exceeds AC16’s accepted already-in-HTTP residual — scenario: a batch contains projects A and B; while A’s HTTP call is running, subagent_start revokes a session in B; B’s already-grouped event subsequently passes _post with its prompt and marker because _post never checks _revoked — fix: re-check revocation at each transmission boundary and before retaining failed deliveries; add a test that revokes B during A’s mocked POST.
F2 [HIGH] sink.py: _revoked / _strip_revoked_spool — Bounded, expiring revocation evidence can disappear before pending and dead-letter prompts are stripped — scenario: an authorized root prompt is spooled, then its session is classified child; more than 2048 distinct revocations arrive before the worker rewrite, evicting the first session; both the rewrite and replay consult only surviving keys, so the first child’s marked prompt remains on disk and can be transmitted — fix: make eviction/expiry fail closed for affected outstanding events, or retain outstanding revocations until sanitization completes; test overflow before a worker pass with pending and dead-letter files.
F3 [HIGH] __init__.py: _denied_sessions / _prompt_decision — Sticky path denial can be evicted independently of positive root evidence, re-enabling capture for the same session contrary to AC4 — scenario: root S is denied in a clone; enough unknown sessions encounter denied paths to evict S from _denied_sessions without touching _session_roots; S then moves to an ordinary directory and its next request is authorized — fix: ensure loss of sticky-denial evidence also invalidates root authorization, using coordinated session state or another bounded fail-closed design; add an independent-map eviction regression test.
F4 [MEDIUM] sink.py: Sink._replay / Sink._post — Legacy spool replay still transmits free-form error_message, despite AC10’s no-error-text contract — scenario: a pre-upgrade spool event contains error_message with prompt/error text; the new replay path strips only PROMPT_FIELDS, leaving error_message in the outgoing HTTP body — fix: remove error_message at the common transmission boundary, including replay, and test a legacy error-event envelope; the supplied error tests cover newly mapped events only.
