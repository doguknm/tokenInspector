F3 [HIGH] backend.md Part B 0b.3/0b.6 versus brief AC5 — Producer retention follows file age rather than prompt capture time, and crash-left `.json.tmp` files have no cleanup policy — scenario: a prompt waits in memory before being spooled, or the process crashes before rename → redacted prompt bytes can survive beyond capture time + 30 days even though the backend discards expired replays — fix: enforce capture-based expiry across spool, dead-letter and temporary files at startup and during maintenance, preserving non-content telemetry where possible; test delayed spooling, dead-letter moves and interrupted writes. Round-1 retention fixes do not cover these copies.
F4 [HIGH] backend.md §6 routing / run reservation — Retry-After is honored only within one task; no provider cooldown is enforced across tasks or new runs — scenario: typesafe-ai returns a wait above the allowance, digitalocean succeeds, then the next task immediately calls typesafe-ai again; likewise a new run can ignore stored retry_not_before — fix: maintain and enforce provider not-before deadlines across tasks and runs, persisting deferred deadlines across restart; test both bypasses. Round-1 item 12 is incomplete.
